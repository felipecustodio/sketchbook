# Names

A generative Brazilian name generator that creates random combinations using real Brazilian names data.

## Features

- **Random Name Generation**: Combines first and last names from a Brazilian names dataset
- **Typography**: Uses custom font rendering for stylized text display
- **Background Images**: Shows Brazilian landscape imagery
- **Interactive**: Click to generate new name combinations

## How It Works

The sketch loads a CSV file containing Brazilian names and randomly combines them to create realistic-sounding name pairs. Each generated name is displayed with custom typography over a background image.

## Usage

1. Open `index.html` in a web browser
2. Click anywhere on the canvas to generate a new random name combination
3. The names are sourced from real Brazilian naming data for authenticity

## Files

- `sketch.js` - Main p5.js sketch with name generation logic
- `names.csv` - Dataset of Brazilian names
- `font.otf` - Custom font for text rendering
- `brazil.jpg` - Background image
- `index.html` - Web page wrapper

## Background

This project explores generative text and Brazilian culture through computational name generation, creating an endless stream of plausible Brazilian names from real data.
