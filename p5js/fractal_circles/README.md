# Fractal Circles

A mesmerizing recursive circle fractal generator that creates beautiful nested patterns.

![Screenshot](https://i.imgur.com/fOyv1fs.png)

## 🎯 Description

This project generates fractal patterns using recursively placed circles. Each circle spawns smaller circles within or around it, creating intricate geometric patterns that demonstrate self-similarity at different scales.

## ✨ Features

- **Recursive Generation**: Circles spawn smaller circles in mathematical patterns
- **Interactive Controls**: Adjust parameters in real-time
- **Smooth Animation**: Fluid transitions and organic growth
- **Color Variations**: Dynamic color schemes based on recursion depth

## 🚀 How to Run

1. Open `index.html` in a modern web browser
2. Or serve locally:
   ```bash
   python -m http.server 8000
   ```
3. Watch the fractal patterns emerge!

## 🎮 Interaction

- **Mouse Movement**: Influences the pattern generation
- **Keyboard Controls**: Various keys modify the fractal parameters
- **Real-time**: All changes are applied immediately

## 🛠️ Technology

- **p5.js**: Core graphics and animation library
- **HTML5 Canvas**: Rendering platform
- **CSS3**: Styling and layout

## 🎨 Inspiration

Inspired by mathematical fractals and the beauty of recursive patterns found in nature, from tree branches to shell spirals.
