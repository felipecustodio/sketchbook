# Harmonograph 3D

An advanced three-dimensional harmonograph simulation that extends the classical 2D harmonograph into 3D space with additional visual effects and controls.

## Features

- **3D Visualization**: Full three-dimensional harmonograph patterns
- **Interactive Camera**: Mouse-controlled 3D camera navigation
- **Noise Integration**: Perlin noise effects for organic variations
- **Animation Controls**: Time-based parameter modulation
- **Advanced Rendering**: Sophisticated 3D curve rendering with depth
- **Multiple Pendulum Systems**: Complex multi-axis pendulum interactions

## How It Works

This 3D version extends the harmonograph concept by:
- Adding a third dimensional axis (Z) to the pendulum equations
- Implementing 3D rotation and perspective transformations
- Using noise functions to create organic variations in the patterns
- Providing interactive camera controls for viewing from different angles

The mathematical model simulates pendulums swinging in three dimensions, with each axis controlled by independent oscillatory functions that can have different frequencies, phases, and amplitudes.

## Controls

- **Mouse**: Drag to rotate the 3D view
- **Scroll**: Zoom in/out
- **Keyboard**: Various keys control different parameters (see code for details)

## Usage

1. Open the `.pde` file in Processing IDE
2. Run the sketch to see the 3D harmonograph
3. Use mouse to rotate and explore the 3D pattern
4. Watch as the pattern evolves over time
5. Experiment with different viewing angles to appreciate the 3D structure

## Technical Features

- **3D Mathematics**: Complex trigonometric functions in three dimensions
- **Perspective Rendering**: Proper 3D perspective projection
- **Real-time Animation**: Smooth time-based parameter changes
- **Noise Functions**: Organic variations using Perlin noise
- **Interactive Controls**: Mouse and keyboard input handling

## Background

While traditional harmonographs were limited to 2D patterns, this digital implementation explores what these beautiful mathematical instruments might look like in three-dimensional space, revealing new layers of complexity and beauty in harmonic motion.
