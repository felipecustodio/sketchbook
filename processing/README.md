# Processing Projects

This directory contains desktop applications built with the [Processing](https://processing.org/) creative coding framework.

## Projects

### 🎵 [harmonograph](./harmonograph/)
Classical harmonograph simulation that creates beautiful, flowing patterns through the interaction of multiple pendulums.
- **Technology**: Processing (Java)
- **Features**: Real-time pattern generation, multiple harmonics
- **How to run**: Open `harmonograph.pde` in Processing IDE

### 🎵 [harmonograph3D](./harmonograph3D/)
3D version of the harmonograph with added noise and animation capabilities.
- **Technology**: Processing (Java) with PeasyCam
- **Features**: 3D visualization, noise effects, frame recording
- **How to run**: Open `harmonograph3D.pde` in Processing IDE

### 🔢 [numeric_sequences](./numeric_sequences/)
Mathematical sequence visualizations including Fibonacci and other numeric patterns.
- **Technology**: Processing (Java)
- **Features**: Multiple sequence types, visual pattern exploration
- **How to run**: Open any `.pde` file in Processing IDE

## Requirements

- [Processing IDE](https://processing.org/download/) (version 3.x or higher)
- Java 8 or higher

## Getting Started

1. Install Processing IDE from [processing.org](https://processing.org/download/)
2. Navigate to any project directory
3. Open the main `.pde` file (usually named after the directory)
4. Click the play button (▶️) in the Processing IDE
5. Enjoy the visual output!

## Creating New Projects

Use the template script from the repository root:
```bash
./templates/new_pde my_new_project
```

This will create a new Processing project in this directory with the basic boilerplate code.
