# Harmonograph

A digital simulation of a classical harmonograph - a mechanical drawing device that creates intricate geometric patterns through the motion of pendulums.

## Features

- **Mathematical Precision**: Simulates the physics of multiple pendulum systems
- **Motion Blur**: Advanced rendering with configurable motion blur effects
- **Recording System**: Built-in animation recording capabilities
- **Visual Effects**: Smooth curves with fade effects and color variations
- **Frame Export**: Save individual frames for creating animations

## How It Works

The harmonograph uses mathematical equations to simulate the motion of pendulums in multiple dimensions. Each pendulum contributes to the final drawing position, creating complex Lissajous-like curves and interference patterns.

The sketch implements:
- Multiple oscillating systems with different frequencies
- Phase relationships between pendulums
- Damping effects for realistic pendulum behavior
- Advanced motion blur rendering for smooth visuals

## Usage

1. Open the `.pde` file in Processing IDE
2. Run the sketch to see the harmonograph in action
3. The pattern will evolve over time as the virtual pendulums swing
4. Press 's' to save individual frames
5. Adjust parameters in the code to explore different patterns

## Technical Details

- **Motion Blur**: Configurable samples per frame and shutter angle
- **Rendering**: High-quality anti-aliased curves
- **Animation**: Smooth interpolation between pendulum positions
- **Export**: Frame sequence export for video creation

## Background

Harmonographs were popular scientific instruments in the 19th century, used to demonstrate principles of harmonic motion and create beautiful geometric art. This digital version captures the mathematical beauty of these mechanical devices.
